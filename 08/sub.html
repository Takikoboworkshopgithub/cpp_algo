補足：DFSを使って全探索を楽に実装しよう

部分集合や順列を再帰的に列挙する。

★ 選ぶ → 探索する → 元に戻す ★

1. 部分集合の全探索

bit全探索で行っていた「各要素を選ぶ／選ばない」という探索は、 DFSでも実装できます。

今回は、選んだ要素をpathに格納します。 同じ要素を重複して選ばないように、次に選ぶ要素を現在の要素より 大きいものに限定します。

N = 3 の場合の探索木

1-1. 探索の考え方

pathに現在までに選んだ要素を格納します。 例えば、path = {1, 2}の場合、 次に選べるのは3だけです。

例えば、1を選んだ後は2、3を追加できます。 2を追加した後は、それより大きい3だけを追加できます。

このように、現在の状態に要素を1つ追加して再帰し、 探索が終わったら追加した要素を取り除きます。

1-2. C++実装

現在の要素より大きい要素だけを次に追加することで、 重複のない部分集合を列挙できます。 

#include <bits/stdc++.h>
using namespace std;

int N;
vector<int> path;

void dfs(int cur) {
    path.push_back(cur);

    // 現在のpathを表示
    for (int v : path) {
        cout << v;
    }
    cout << endl;

    // 自分より大きい要素を追加して探索
    for (int i = cur + 1; i <= N; i++) {
        dfs(i);
    }

    // 再帰から戻ったら最後の要素を削除
    path.pop_back();
}

int main() {
    cin >> N;

    for (int i = 1; i <= N; i++) {
        dfs(i);
    }
}
pathの状態を元に戻す
push_back()で要素を追加し、 再帰呼び出しが終わったらpop_back()で取り除きます。 このように、探索前の状態に戻すことをバックトラックといいます。

2. 順列の全探索

順列全探索に対しても、DFSは有効です。

部分集合とは異なり、順列では選ぶ順番も区別します。 そのため、次に選ぶ要素を大きいものに限定することはできません。

N = 3 の場合の順列探索木

各段階で未使用の要素を追加し、3つすべて選ぶと順列が完成します。

2-1. 探索の考え方

pathに現在までに選んだ順番を格納し、 used[i]で要素iをすでに使用したかどうかを管理します。

path

現在までに選んだ要素を、選んだ順番で保存します。

used

各要素をすでに使用したかどうかを管理します。

まだ使用していない要素を1つ選び、pathに追加します。 その要素を使用済みにして、次の要素をDFSで探索します。

pathにN個の要素が格納されたら、1つの順列が完成です。 再帰から戻るときには、追加した要素を取り除き、未使用の状態に戻します。

2-2. C++実装 

#include <bits/stdc++.h>
using namespace std;

int N;
vector<int> path;
vector<bool> used;

void dfs() {
    // N個すべて選んだら完成
    if (path.size() == N) {
        for (int v : path) {
            cout << v;
        }
        cout << endl;
        return;
    }

    // まだ使用していない要素を探索
    for (int i = 1; i <= N; i++) {
        if (used[i]) continue;

        // 要素を追加
        path.push_back(i);
        used[i] = true;

        dfs();

        // 元の状態に戻す
        path.pop_back();
        used[i] = false;
    }
}

int main() {
    cin >> N;
    used.resize(N + 1, false);

    dfs();
}
usedで使用状況を管理する
順列では同じ要素を2回使えません。 used[i]がtrueなら、その要素はすでに使用済みです。 再帰から戻ったらfalseに戻すことで、別の順列を探索できます。

3. 配列を使い回すDFS

木のDFSでは、「根から今いる頂点まで、どの頂点を通ってきたか」を 記録したい場面がよくあります。この「通ってきた道」をpathという配列で管理します。

たとえば、次の木を頂点1からDFSする場合を考えます。

例題の木（頂点1が根）

頂点1の子は2と3、頂点2の子は4と5、頂点3の子は6です。

3-1. 探索の考え方

再帰関数にpathを毎回値渡しすれば実現できますが、 呼び出すたびに配列がまるごとコピーされてしまいます。 道が長くなるほど、コピーのコストも大きくなります。

そこで、配列を1つだけ用意して、すべての再帰呼び出しで共有します。 その代わり、次の2つのルールを守ります。

頂点に入るとき

push_back(v)で、自分をpathの末尾に追加します。

頂点から出るとき

pop_back()で、自分をpathの末尾から取り除きます。

子の探索がすべて終わったら自分を取り除くので、親に戻った時点で pathは入る前の状態に戻っています。

3-2. 実際の動きを追ってみよう

push_backとpop_backのたびに、pathがどう変化するかを追います。 右側の枠がpathの中身で、点線は空きを表します。 黄色が、いま追加した要素です。

path の変化（上から順に実行）

⑦で頂点2を取り除いているので、⑧で頂点3に入ったときpathは正しく[1, 3]になります。

3-3. C++実装

入力は、頂点数Nと、N - 1本の辺です。 頂点に入るたびに、現在のpathを表示します。 

#include <bits/stdc++.h>
using namespace std;

int N;
vector<vector<int>> G;
vector<int> path;  // すべての呼び出しで共有する

void dfs(int v, int parent) {
    // 入る：自分を追加
    path.push_back(v);

    // 現在のpathを表示
    for (int i = 0; i < (int)path.size(); i++) {
        if (i > 0) cout << " → ";
        cout << path[i];
    }
    cout << endl;

    // 子を探索
    for (int next : G[v]) {
        if (next == parent) continue;
        dfs(next, v);
    }

    // 出る：自分を削除
    path.pop_back();
}

int main() {
    cin >> N;
    G.resize(N + 1);

    for (int i = 0; i < N - 1; i++) {
        int a, b;
        cin >> a >> b;
        G[a].push_back(b);
        G[b].push_back(a);
    }

    dfs(1, 0);
}
