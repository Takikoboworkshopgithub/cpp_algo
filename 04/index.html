第04講：尺取り法

「右端を戻さない」ことで、区間を高速に調べよう。
区間の性質を見抜けば、全探索を線形時間にできる。

★ 2つの端点を、無駄なく動かせ ★

0. 今回の目標

尺取り法は、区間の左端と右端を少しずつ動かしながら、連続する部分列を効率よく調べるテクニックです。条件に合う区間の個数を数えたり、区間の長さの最大値・最小値を求めたりするときに使えます。

今回のゴール：「総和が 7 以下となる連続区間はいくつあるか？」を、全探索の O(N³) から尺取り法の O(N) へ改善します。

1. 問題

次の配列を考えます。

A = {0, 1, 2, 3, 4, 5},　target = 7

連続する区間のうち、総和が 7 以下となるものはいくつあるでしょうか？

左端 l と右端 r を決めて表します。

半開区間 [left, right) のイメージ

左端 left は含み、右端 right は含みません。したがって、区間の長さは right - left です。

1.1 まずは全探索してみる：O(N³)

左端 l と右端 r をすべて試し、そのたびに区間の総和を最初から計算します。区間の選び方が O(N²) 通りあり、総和の計算に最大 O(N) かかるため、全体で O(N³) です。

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> A = {0, 1, 2, 3, 4, 5};
    int N = A.size();
    int target = 7;
    long long cnt = 0;

    for (int l = 0; l < N; ++l) {
        for (int r = l + 1; r <= N; ++r) {
            int sum = 0;
            for (int i = l; i < r; ++i) {
                sum += A[i];
            }
            if (sum <= target) ++cnt;
        }
    }
    cout << cnt << endl; // 13
}

出力は 13 です。ただし、同じ区間の総和を何度も計算しているため、無駄が多くあります。

1.2 累積和を使う：O(N²)

累積和を用意しておけば、区間 [l, r) の総和は prefix[r] - prefix[l] で O(1) で求められます。これで全体は O(N²) になります。

vector<long long> prefix(N + 1, 0);
for (int i = 0; i < N; ++i) {
    prefix[i + 1] = prefix[i] + A[i];
}

long long cnt = 0;
for (int l = 0; l < N; ++l) {
    for (int r = l + 1; r <= N; ++r) {
        if (prefix[r] - prefix[l] <= target) ++cnt;
    }
}

もっと調べる区間の数を減らすことを考えます。

2. 尺取り法

アルゴリズムの考え方

  1. sum を「現在の区間 [left, right) の総和」として管理する。
  2. sum + A[right] <= target である限り、右端を伸ばす。
  3. 現在の left で作れる有効な区間は right - left 個なので、答えに加える。
  4. 次の左端に向けて A[left] を総和から引く。

2.1 実際の動き

各 left で、条件を満たす限り right を進めます。表の「追加できない要素」は、右端をそれ以上進められない理由です。

left最後の区間 [left, right)次に追加する要素加算する数累計
0[0, 4) = {0, 1, 2, 3}
sum = 6		4 を足すと 10。7 を超える4 − 0 = 44
1[1, 4) = {1, 2, 3}
sum = 6		4 を足すと 10。7 を超える4 − 1 = 37
2[2, 4) = {2, 3}
sum = 5		4 を足すと 9。7 を超える4 − 2 = 29
3[3, 5) = {3, 4}
sum = 7		5 を足すと 12。7 を超える5 − 3 = 211
4[4, 5) = {4}
sum = 4		5 を足すと 9。7 を超える5 − 4 = 112
5[5, 6) = {5}
sum = 5		配列の末尾に到達6 − 5 = 113

例えば left = 1 のとき、有効な区間は [1, 2)、[1, 3)、[1, 4) の3つです。右端が right = 4 なので、区間の個数は right - left = 4 - 1 = 3 と分かります。

このようにして、各 left について条件を満たす区間をまとめて数えます。合計は 13 個です。

元の文章では「配列の範囲を超える or 右端を増やしても条件を満たす」と書かれていましたが、実装では right < N かつ sum + A[right] <= target の両方を満たす必要があります。配列の範囲外を参照しないことにも注意してください。

また、left == right は区間が空で、左端の要素をまだ総和に加えていない状態です。そのときは引き算をせず、right を1つ進めて次の位置に合わせます。

2.2 C++で実装する

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> A = {0, 1, 2, 3, 4, 5};
    int N = A.size();
    int target = 7;

    long long cnt = 0;
    long long sum = 0;
    int right = 0;

    for (int left = 0; left < N; ++left) {
        // 右端を伸ばせるだけ伸ばす
        while (right < N && sum + A[right] <= target) {
            sum += A[right];
            ++right;
        }

        // [left, right) のうち条件を満たす区間は right - left 個
        cnt += right - left;

        // 次の left に備える
        if (left == right) {
            ++right; // 空区間なら、right を左端より先に進める
        } else {
            sum -= A[left];
        }
    }

    cout << cnt << endl; // 13
}
計算量は O(N)。 left は最大 N 回進みます。重要なのは、right も配列の先頭から末尾までしか進まず、途中で左に戻らないことです。各要素の追加・削除は定数回なので、全体でも線形時間になります。

進み方に関する参考画像。この場合は、総和が6以下で進めている

3. 尺取り法が使える条件

尺取り法は、どんな条件に対しても使えるわけではありません。端点を動かしたときに、条件を満たすかどうかが都合よく変化する必要があります。よく使う形を2つ見てみましょう。

パターン A：条件を満たす区間の部分区間も、条件を満たす

例：「総和が K 以下」「同じ値を重複して含まない」「狭義単調増加」

パターン B：条件を満たす区間を拡張しても、条件を満たす

例：「総和が K 以上」（要素がすべて非負の場合）

この2つは区別して考えてください。どちらも区間の性質に単調性がある例ですが、どちらの形を使うかは、問題で与えられた条件によって変わります。

3.1 パターン A：条件を満たす区間の部分区間も満たす

今回の「総和が 7 以下」という条件で、配列の要素がすべて 0 以上だとします。ある区間の総和が 7 以下なら、その区間から要素を取り除いても総和は増えません。したがって、部分区間の総和も 7 以下です。

○ 条件を満たす

[1, 2, 3] → sum = 6

部分区間 [1, 2] の総和は 3。こちらも 7 以下です。

× 負数があると崩れる

[1, 2, 3, 4, 5, -15]

全体の総和は 0 ですが、部分区間 [1, 2, 3, 4, 5] の総和は 15。全体が条件を満たしても、部分区間が条件を満たすとは限りません。

このパターンでは、左端を固定すると「右端がある場所までは条件を満たすが、そこから先は満たさない」という境界ができます。さらに left を右に動かすと、条件を満たす右端の最大値は後戻りしません。この性質を使って right を使い回せます。

3.2 パターン B：条件を満たす区間を拡張しても満たす

今度は「総和が 5 以上」という条件を考えます。要素がすべて 0 以上なら、総和が 5 以上の区間に要素を追加しても、総和は減りません。したがって、拡張後も総和は 5 以上です。

[1, 2, 3] の総和は 6 ≥ 5

右側に 4 を追加 → [1, 2, 3, 4] の総和は 10 ≥ 5

このような条件は、例えば「総和が K 以上となる区間の最小の長さ」を探すときに使えます。

参考：総和が target 以上となる最短区間の長さ（要素が非負の場合）

long long sum = 0;
int right = 0;
int ans = N + 1; // 条件を満たす区間がない場合の番兵値

for (int left = 0; left < N; ++left) {
    while (right < N && sum < target) {
        sum += A[right];
        ++right;
    }
    if (sum >= target) {
        ans = min(ans, right - left);
    }
    if (left == right) {
        ++right;
    } else {
        sum -= A[left];
    }
}

if (ans == N + 1) cout << -1 << endl;
else cout << ans << endl;

※ このコードは「総和が target 以上」を扱う別パターンの例です。今回の数え上げコードと条件式を混同しないようにしましょう。なお、実際の問題では target の範囲や空区間の扱いなど、制約に応じた確認が必要です。

3.3 二分探索法との関係

左端を固定したとき、条件を満たす右端がある境界を持つ点は、二分探索法と似ています。二分探索法では各左端について境界を探すため、全体で O(N log N) になることがあります。一方、尺取り法では左端を進めても右端を戻さずに済む場合があり、全体を O(N) にできます。ただし、条件の単調性や区間の性質が必要であり、何でも尺取り法に置き換えられるわけではありません。

5. まとめ

  • 尺取り法は、連続区間の左端と右端を動かし、区間を効率よく調べる手法。
  • 今回の「総和が K 以下」の数え上げは、要素がすべて非負なら使える。
  • 条件を満たす右端までの区間数は right - left でまとめて数えられる。
  • left と right がそれぞれ高々 N 回程度しか進まないため、全体は O(N)。
  • 負数がある場合など、条件の単調性が崩れるときは、そのまま適用できない。
