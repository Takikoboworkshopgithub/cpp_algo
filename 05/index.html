0. グラフ理論

グラフ理論は、物事や事象を「点」と「点をつなぐ線」に置き換えて考察する分野です。現実の複雑な関係を、頂点と辺からなる構造として捉えます。

駅と路線

駅を頂点、駅間の路線を辺として表します。

四色問題

都道府県を頂点、隣り合う県を辺で結ぶと、地図の彩色問題として考えられます。

ほかにも、一筆書きができるか、ルービックキューブをどう解くか、割りばしゲームで勝てるか、といった問題をグラフとして表現できます。状態を頂点、状態間で可能な操作を辺とみなす方法もあります。

重要：問題をそのまま眺めるのではなく、何を頂点とし、何を辺とするかを考えると、グラフのアルゴリズムに持ち込めることがあります。

1. グラフの用語

以下は AtCoder の用語解説を参考に、初学者向けにかみ砕いた説明です。厳密な定義や補足はAtCoder の解説 ➜も確認してください。

頂点・ノード

グラフを構成する「点」です。

辺・エッジ

頂点と頂点をつなぐ「線」です。

次数

無向グラフでは、その頂点につながっている辺の本数です。

パス

辺をたどって頂点から頂点へ移動する道筋です。例：生田 → 向ヶ丘遊園 → 登戸。

1.1 無向辺と有向辺

無向辺：両方向に移動できる

A から B、B から A のどちらにも進めます。

有向辺：向きがある

A から B には進めますが、辺を逆向きにたどることはできません。

無向辺だけからなるものを無向グラフ、有向辺だけからなるものを有向グラフと呼びます。

1.2 そのほかの用語

用語意味イメージ
多重辺同じ2頂点を結ぶ辺が複数あること。A と B の間に線が2本以上
自己ループある頂点から同じ頂点へ戻る辺。A → A
単純グラフ多重辺も自己ループもないグラフ。各頂点間に同じ辺は1本以下
サイクル・閉路辺をたどって出発した頂点に戻れる一周。A → B → C → A
木連結で、閉路を持たない無向グラフ。枝分かれはあるが一周できない
二部グラフ頂点を2グループに分け、同じグループ内には辺がないグラフ。左グループと右グループだけが接続
完全グラフ異なる任意の2頂点が辺で結ばれているグラフ。すべての頂点ペアを接続

同じグラフ、違う配置

頂点の位置や線の曲がり方ではなく、どの頂点同士がつながっているかが重要です。

完全グラフの注意

完全グラフでは、すべての異なる頂点ペアが直接つながっています。単に多角形の辺だけを描いた図ではなく、対角線も含めた接続です。

2. 木の用語

ここでいう「木」は街路樹ではなく、グラフ理論の木構造です。木構造は、ディレクトリや家系図などにも現れます。

木構造

ディレクトリ

root/
├─ src/
│　└─ main.cpp
└─ data/

家系図の例

根（root）

木の中で基準として選ぶ頂点です。根の選び方によって親子関係が変わります。

親・子

根からたどったとき、ある頂点から次の頂点へ進む関係を親・子と呼びます。

葉

子を持たない頂点です。根以外の頂点なら、木の葉は次数1になります。

深さ

根からその頂点までに通る辺の本数です。

2.1 二分木と完全二分木

二分木は、各頂点が持つ子の数が高々2個の木です。Yes / No の二択で分岐する質問や、トーナメント表、機械学習の決定木などに登場します。

3. AtCoder Library（ACL）

AtCoder Library（ACL）は、AtCoder 公式が提供する C++ 用のアルゴリズム・データ構造ライブラリです。自分で毎回実装しなくても、定番の機能を呼び出せます。

通常の利用：環境を整えたうえで #include <atcoder/all> または必要な機能のヘッダーを読み込みます。

3.1 インストール

ACL をまだ導入していない場合は、次の動画を参考に環境構築してください。Windows + WSL2 向けの手順です。Mac では手順が異なる場合があります。

環境構築の動画を開く ➜

環境構築がどうしても難しい場合は、以下の UnionFind 実装を C++ ファイルに貼り付けて利用する方法もあります。ただし、これは ACL の dsu の機能を抜粋した代替実装です。

代替実装を表示（クリック） 
#include <bits/stdc++.h>
using namespace std;

struct dsu {
    vector<int> parent_or_size;
    dsu(int n) : parent_or_size(n, -1) {}

    int leader(int a) {
        if (parent_or_size[a] < 0) return a;
        return parent_or_size[a] = leader(parent_or_size[a]);
    }

    bool same(int a, int b) {
        return leader(a) == leader(b);
    }

    int size(int a) {
        return -parent_or_size[leader(a)];
    }

    int merge(int a, int b) {
        int x = leader(a), y = leader(b);
        if (x == y) return x;
        if (-parent_or_size[x] < -parent_or_size[y]) swap(x, y);
        parent_or_size[x] += parent_or_size[y];
        parent_or_size[y] = x;
        return x;
    }
};

4. UnionFind

UnionFind（素集合データ構造、Disjoint Set Union / DSU）は、要素を互いに重ならないグループに分け、グループの統合や、同じグループかどうかの判定を効率よく行うデータ構造です。

イメージ：グループを統合する

4.1 基本操作

操作意味例
dsu uf(N)N 個の要素を、それぞれ別のグループとして初期化最初は N グループ
uf.merge(a, b)a と b のグループを統合する辺 (a, b) を追加するイメージ
uf.same(a, b)同じグループかを true / false で返す連結しているか判定
uf.size(a)a が属するグループの要素数グループに 3 要素あるなら 3
uf.leader(a)a のグループの代表頂点を返す同じグループなら同じ代表
uf.groups()全グループを二次元配列として返す{{0, 2, 4, 7}, {3, 5}, {6}} など

ACL では次のヘッダーを使います。atcoder/all を読み込んでいるなら、個別に追加する必要はありません。

#include <atcoder/dsu>

4.2 使用例

#include <bits/stdc++.h>
#include <atcoder/dsu>
using namespace std;
using namespace atcoder;

int main() {
    int node_num = 3; // 頂点数
    int a = 0, b = 1, c = 2;

    dsu uf(node_num); // 3頂点、辺はまだない

    uf.merge(a, b); // 0 と 1 を同じグループにする

    cout << uf.same(a, b) << endl; // 1 (true)
    cout << uf.same(a, c) << endl; // 0 (false)
    cout << uf.size(a) << endl;    // 2
    cout << uf.leader(a) << endl;  // 代表頂点（0とは限らない）

    return 0;
}

多くの競技プログラミング環境では、UnionFind の各操作は償却計算量でほぼ O(1) とみなせるほど高速です。厳密には、経路圧縮と union by size により、操作あたり O(α(N)) です。

4.3 uf.groups() の例

例えば、グループが次のように分かれているとします。

auto groups = uf.groups();
// 例：{{0, 2, 4, 7}, {3, 5}, {6}}

グループの並び順や、各グループ内の要素順に依存した処理は避けてください。代表頂点は、必ずしも最小番号とは限りません。

5. 例題：連結判定クエリ

AtCoder Library Practice Contest の Practice2 A - Disjoint Set Union ➜ を扱います。

問題文

N 頂点・0 辺の無向グラフに Q 個のクエリが与えられます。

  • 0 u v：頂点 u と頂点 v を結ぶ辺を追加する。
  • 1 u v：u と v が連結なら 1、そうでなければ 0 を出力する。

ここでいう「連結」とは、辺を何本かたどって一方の頂点からもう一方へ到達できることです。辺を追加するたびにグループを統合し、判定クエリでは同じグループかどうかを調べれば解けます。

#include <bits/stdc++.h>
#include <atcoder/dsu>
using namespace std;
using namespace atcoder;

int main() {
    int N, Q;
    cin >> N >> Q;

    dsu d(N);

    for (int i = 0; i < Q; i++) {
        int t, u, v;
        cin >> t >> u >> v;

        if (t == 0) {
            d.merge(u, v);
        } else if (t == 1) {
            cout << d.same(u, v) << endl;
        }
    }
    return 0;
}
読み解きポイント：
  • dsu d(N) は、頂点 0 から N-1 までを別々のグループで初期化します。
  • d.merge(u, v) は、u と v のグループを統合します。
  • d.same(u, v) は、2頂点が同じグループに属するかを返します。C++ では true は 1、false は 0 として出力されます。

6. まとめ

  • グラフは頂点と辺で、物事の関係や状態遷移を表現する。
  • 辺には無向辺と有向辺があり、グラフの種類や性質を表す用語がある。
  • 木は、連結で閉路を持たない無向グラフとして考えられる。
  • ACL は C++ 用のアルゴリズム・データ構造ライブラリ。
  • UnionFind は、グループの統合と、同じグループかどうかの判定を高速に行う。
  • 連結判定クエリでは、辺の追加を merge、連結判定を same で処理できる。
自分で確認：「なぜ same(u, v) で連結判定ができるのか」「merge を何度呼んでもよいのはなぜか」を、自分の言葉で説明できるようにしましょう。
