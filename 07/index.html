1. 多点BFS

前回は、1つのスタート地点からBFSを行いました。今回は、スタート地点が複数ある場合を考えます。 例えば、複数の場所にある避難所から、各地点までの最短距離を求めるような場面です。

多点BFSの考え方は通常のBFSとほとんど同じで、探索開始時にすべての始点をQueueに入れ、距離を0にすることだけです。

グリッドの場合、初期化部分は次のようになります。

// dist配列を初期化（-1で未訪問を表す）
vector<vector<int>> dist(H, vector<int>(W, -1));

// 多点BFS用のQueue
queue<pair<int, int>> que;

// すべての始点をQueueに投入し、距離0で初期化
for (auto &st : starts) {
    dist[st.first][st.second] = 0;
    que.push(st);
}

// 以降の探索処理は通常のBFSと同じ

2. 木の直径

2-1. 木の直径とは

木の直径とは、木に含まれる2つの頂点間の距離の最大値です。 例えば、次の図のような木では、頂点5と頂点6の間の距離が最も長く、その長さが木の直径になります。今回の場合は5です

木の直径の例

図では、最も離れた2頂点を結ぶ経路の長さが直径です。

木の直径は、BFSを2回行うことで求められます。

  1. 木の中からランダムな頂点を1つ選びます(通常は0を選ぶ)。
  2. その頂点を始点としてBFSを行います。
  3. 最も遠かった頂点を選び、その頂点からもう一度BFSを行います。
  4. 2回目のBFSで得られた最大距離が、木の直径です。

BFSを2回書くのは少し面倒です。 そこで、同じ処理をまとめて使えるようにするために、C++のラムダ式を学びましょう。

2-2. ラムダ式とは

ラムダ式とは、関数のように使える処理を、その場で定義できるC++の機能です。 AtCoderでは、新しい関数は基本的にラムダ式で書くと便利です！

main文の変数を引数に取らずとも利用できるのが便利なところです。
例えば、配列の要素について「A未満ならBに置き換える」という処理を考えてみます。

通常の関数で書く場合

#include <bits/stdc++.h>
using namespace std;

vector<int> change(vector<int> X, int A, int B) {
    for (int &x : X) {
        if (x < A) x = B;
    }
    return X;
}

int main() {
    vector<int> X = {3, 7, 2, 8, 5, 1};

    int A = 5;
    int B = 0;

    X = change(X, A, B);

    for (int x : X) cout << x << " ";
    cout << endl;
}

ラムダ式で書く場合

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> X = {3, 7, 2, 8, 5, 1};

    int A = 5;
    int B = 0;

    // ラムダ式で関数を定義
    auto change = [&](vector<int> X) {
        for (int &x : X) {
            if (x < A) x = B;
        }
        return X;
    };//ここの「;」忘れがち

    X = change(X);

    for (int x : X) cout << x << " ";
    cout << endl;
}

ラムダ式の基本形は、auto 関数名 = [キャプチャ](引数) { 処理 };です。 この例の[&]は、ラムダ式の外側にある変数を参照でキャプチャする指定です。 そのため、外側で定義したAとBを引数として渡さずに使えます。

  • [&]：外側の変数を参照キャプチャする。
  • [=]：外側の変数を値キャプチャする。
  • []：外側の変数をキャプチャしない。

※キャプチャした変数を変更する必要があるか、ラムダ式の外側の変数の寿命が十分かにも注意しましょう。

2-3. sortとラムダ式

ラムダ式は、sortの比較関数として渡す使い方も便利です。 比較関数は、2つの要素を受け取り、「aをbより前に置くべきか」をbool値で返します。 

vector<int> Array = {3, 1, 4, 15, 92, 653, 5};

// 小さい順（デフォルト）
sort(Array.begin(), Array.end());

// 大きい順
sort(Array.begin(), Array.end(),
     [](int a, int b) { return a > b; });

// 変数offsetに近い順
int offset = 90;
sort(Array.begin(), Array.end(),
     [&](int a, int b) {
         return abs(a - offset) < abs(b - offset);
     });

// 文字列に変換したときの長さ順
sort(Array.begin(), Array.end(),
     [](int a, int b) {
         return to_string(a).size() < to_string(b).size();
     });

3つ目の例では、外側で定義したoffsetを[&]でキャプチャしています。 4つ目の例では外側の変数を使わないため、[]で十分です。

比較関数の注意：sortに渡す比較関数は、大小関係が矛盾しないように書く必要があります。 同じ値を比較したときにtrueを返すような条件（例えばa >= b）にはしないでください。

2-4. BFSをラムダ式にする

それでは、BFSをラムダ式にしてみましょう。 次の関数は、始点startからBFSを行い、最も遠い頂点と、その頂点までの距離を返します。 

auto bfs = [&](int start) {
    vector<int> dist(N, -1);
    queue<int> que;

    dist[start] = 0;
    que.push(start);

    while (!que.empty()) {
        int v = que.front();
        que.pop();

        for (int nv : G[v]) {
            if (dist[nv] != -1) continue;

            dist[nv] = dist[v] + 1;
            que.push(nv);
        }
    }

    int farthest = start;

    for (int i = 0; i < N; i++) {
        if (dist[i] > dist[farthest]) {
            farthest = i;
        }
    }

    return make_pair(farthest, dist[farthest]);
};

// 1回目：適当な頂点0から最も遠い頂点uを探す
auto [u, d1] = bfs(0);

// 2回目：uから最も遠い頂点までの距離が直径
auto [v, diameter] = bfs(u);

[&]によって、ラムダ式の外側にあるNやGを利用できます。 これで、BFSの処理を1か所にまとめ、始点を変えて2回呼び出せるようになりました。

auto [u, d1]は、返されたpairの中身をそれぞれuとd1に取り出す構造化束縛です。 1回目の距離d1は、このコードでは使いません。

木の直径の計算量：隣接リストを使ったBFSはO(N + M)です。 木では辺数M = N - 1なので、BFSを2回行っても全体でO(N)です。

3. 経路復元

BFSはスタート地点から各頂点までの最短距離を求められます。 しかし、距離だけでは「実際にどの頂点を通ればよいか」は分かりません。 そこで、最短経路そのものを取り出す経路復元を行います。

方法はシンプルです。各頂点について、その頂点にどこから来たかを記録しておきます。 ゴールに到着したら、記録をたどって1つ前、さらにその前へと戻れば、経路を復元できます。

親（直前の頂点）をたどって経路を復元する

ゴールから始点に向かって逆向きにたどります。

次のコードでは、prev[v]に頂点vの直前の頂点を保存します。

vector<int> prev(N, -2); // -2：まだ経路が決まっていない
prev[0] = -1;             // -1：始点。これ以上戻れない

queue<int> que;
que.push(0);

while (!que.empty()) {
    int current = que.front();
    que.pop();

    for (int next : G[current]) {
        if (prev[next] != -2) continue;

        prev[next] = current;
        que.push(next);
    }
}

prev[next] = currentとしている部分が重要です。 頂点nextを初めて発見したときに、直前にいた頂点currentを記録します。 BFSでは初めて発見したときの経路が最短経路なので、この記録を使えば最短経路を復元できます。

ゴールから始点まで逆向きにたどり、最後に反転すると、始点からゴールの順番になります。

int GOAL = /* ゴールの頂点番号 */;

// 到達できなかった場合
if (prev[GOAL] == -2) {
    cout << "到達できません" << endl;
} else {
    vector<int> path;

    int current = GOAL;
    while (current != -1) {
        path.push_back(current);
        current = prev[current];
    }

    reverse(path.begin(), path.end());

    for (int v : path) {
        cout << v << " ";
    }
    cout << endl;
}
ポイント：prevの-2と-1は役割が違います。 復元した配列はゴールから始点の順になるため、reverseで反転します。

4. 0-1 BFS

RPGなどのゲームでは、ワープゾーンや、滑り始めると止まれない氷のマスなど、移動の仕組みによって移動コストが変わることがあります。 このように、頂点から頂点へ移動するコストが0または1になる場合に使えるのが0-1 BFSです。

通常のBFSでは、1回移動するたびに距離を1増やしていました。 これは、すべての辺の移動コストが1であると考えられます。 では、移動コストが0の辺と1の辺が混ざっていたらどうすればよいでしょうか。

0-1 BFSでは、通常のQueueの代わりにDeque（デック）を使います。 コストが0の辺を通った場合はDequeの先頭に、コストが1の辺を通った場合は末尾に追加します。

4-1. Dequeの使い方

Dequeは、先頭と末尾の両方から要素を追加・削除できるデータ構造です。 QueueとStackの両方のような操作ができ、両端への追加・削除はいずれもO(1)で行えます。 

int main() {
    deque<int> dq = {20, 30};

    // 先頭と末尾への追加（O(1)）
    dq.push_front(10); // {10, 20, 30}
    dq.push_back(40);  // {10, 20, 30, 40}

    // 要素へのアクセス
    cout << dq[2] << endl;      // 30
    cout << dq.front() << endl; // 10
    cout << dq.back() << endl;  // 40

    // 先頭と末尾の削除（O(1)）
    dq.pop_front(); // {20, 30, 40}
    dq.pop_back();  // {20, 30}

    return 0;
}

なお、Dequeは添字によるアクセスもO(1)です。 dq[2]のように、配列と同じ感覚で要素を参照できます。

4-2. 0-1 BFSの実装

0-1 BFSの基本的な流れはBFSと同じです。 ただし、次の頂点へ移動するコストに応じて、Dequeへの追加位置を変えます。

コストが0の場合

push_frontでDequeの先頭に追加します。

コストが1の場合

push_backでDequeの末尾に追加します。

頂点は常にDequeの先頭から取り出します。 コスト0の移動を優先して処理し、コスト1の移動は後ろに回すことで、距離の小さい候補から処理できるようにします。 

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M, s;
    cin >> N >> M >> s;

    // edges[i]に(j, c)があるとき、
    // iからjへコストcで移動できる
    vector<vector<pair<int, int>>> edges(N);

    for (int i = 0; i < M; i++) {
        int a, b, c;
        cin >> a >> b >> c;
        edges[a].push_back({b, c});

        // 無向グラフとして扱う場合は、逆向きも追加する
        // edges[b].push_back({a, c});
    }

    const int INF = 1e9;
    vector<int> dist(N, INF);

    deque<int> que;
    dist[s] = 0;
    que.push_front(s);

    while (!que.empty()) {
        int i = que.front();
        que.pop_front();

        for (auto [j, c] : edges[i]) {
            int d = dist[i] + c;

            if (d < dist[j]) {
                dist[j] = d;

                if (c == 0) {
                    que.push_front(j);
                } else {
                    que.push_back(j);
                }
            }
        }
    }

    // dist[v]が始点sから頂点vまでの最短距離
    for (int v = 0; v < N; v++) {
        if (dist[v] == INF) cout << v << ": unreachable" << endl;
        else cout << v << ": " << dist[v] << endl;
    }
}

edges[i]には、移動先の頂点jと、その辺のコストcをペアで保存しています。 そのため、for (auto [j, c] : edges[i])で移動先とコストを取り出せます。

適用できる条件：0-1 BFSを使えるのは、各辺のコストが0または1の場合です。 コストが2以上の値も含まれる一般の非負重み付きグラフでは、Dijkstra法を使います。これはまた今度扱います。

また、上のコードは有向グラフとして辺を登録しています。 無向グラフにしたい場合は、コメントにあるように逆向きの辺も追加してください。

5. まとめ

今回学んだBFSの応用を整理しましょう。

多点BFS

複数の始点を最初にQueueへ入れることで、複数地点から同時に探索する。

木の直径

木に対してBFSを2回行い、最も離れた2頂点間の距離を求める。

ラムダ式

処理をその場で定義できる。キャプチャを使えば外側の変数も利用できる。

経路復元

各頂点の直前の頂点を記録し、ゴールから逆向きにたどって経路を取り出す。

0-1 BFS

辺のコストが0または1のとき、Dequeの先頭・末尾を使い分けて最短距離を求める。

BFSの応用でも、基本は「どの頂点を次に調べるか」「距離をいつ更新するか」です。 QueueやDequeの動きと、距離配列の更新タイミングを意識してコードを読んでみましょう。
